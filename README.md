# SGLang Decode Task Scheduling

基于 SGLang 的分页 GQA Decode 任务划分优化。围绕 GPU 紧凑任务表、持久 CTA 调度、分页寻址与 CUDA Graph 元数据复用实现独立扩展。

本仓库根据保留下来的项目设计与简历重建，提交日期反映本次重建时间，不是历史工程的提交记录。

## 实现范围

- 请求／分片 SoA 记录、稳定工作量分桶、直接索引。
- 紧凑轮转、直接表轮转、贪心静态、动态单任务和限量打包对照。
- Triton 分页 GQA、局部 softmax 状态与有效分片归并。
- 固定容量缓冲、逐层计数器与同一步兼容层的只读计划共享。
- SGLang 接入、输出参考、缩批回放用例与分层计时入口。
